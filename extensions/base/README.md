# Base

Always-on base extension.

- Auto-pin Gmail and Google Calendar tabs.
- Make Gmail suck less: restore the older, denser styling, show email bodies in a fixed-width font, and hide nags and AI Overview.
- Open the pull request itself when a GitHub commit-range link (`/pull/<number>/changes/<sha>..<sha>`) points at commits a force-push rewrote away.
- Add an LGTM button beside Submit review on a GitHub pull request's changes page that approves with an `LGTM` comment in one click.
- Add a Done merged button to GitHub's notifications page that marks every merged pull request's notification on the page as done in one click.
